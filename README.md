# Actividad2.1 
Objetivo
Alerta emergente: Uso de alert() para mostrar un cuadro de mensaje.
Mensaje en el documento: Inserción de texto directamente en el cuerpo del HTML (ej. etiqueta <p>).
Impresión en consola: Uso de console.log() para registrar información en la consola del navegador.
Mensaje en contenedor <div>: Manipulación del DOM para colocar texto dentro de un elemento <div> específico.
